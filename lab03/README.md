# Лабораторная работа 3: Интерфейсы и полиморфизм

Условие: [`assignments/lab03-polymorphism.md`](../assignments/lab03-polymorphism.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab03 test
```

Windows PowerShell: `.\\mvnw.cmd -pl lab03 test`.

Основной код размещайте в `src/main/java/edu/course/lab03/`, тесты — в `src/test/java/edu/course/lab03/`. В начале каждого Java-файла укажите `package edu.course.lab03;`.

Модуль независим от остальных лабораторных. Если нужны модели из предыдущей работы, перенесите и при необходимости адаптируйте только нужные классы в этот модуль. Начальная успешная сборка не является выполнением задания: создайте реализацию и собственные тесты по условию.


## Выполнено

### Подготовительная часть

- Создан интерфейс DiscountPolicy.
- Реализованы NoDiscount и PercentDiscount.
- Создан PriceCalculator с внедрением политики через конструктор.
- Проверена возможность использования разных политик скидок.

### Обязательная часть — инженерия систем искусственного интеллекта

- Создан интерфейс NormalizationStrategy.
- Реализована MinMaxNormalization.
- Реализована MeanCenteringNormalization.
- Создан FeatureProcessor с внедрением стратегии через конструктор.
- Проверена заменяемость алгоритмов нормализации.

### Основные решения

- Используются интерфейсы для определения общего контракта.
- Используется композиция.
- Конкретные реализации передаются через конструкторы.
- Обработчики не создают стратегии самостоятельно.
- Входные массивы не изменяются.
- Для каждой реализации написаны JUnit-тесты.
- Не используются instanceof и проверки типа реализации.
